# Membership App Web

A modern membership management admin dashboard for handling members, plans, billing, reports, and settings.

## Stack

- React
- Vite
- React Router DOM

## Getting started

```bash
npm install
npm run dev -- --host
```

Then open the local URL that Vite prints in the terminal.

## Production build

```bash
npm run build
```

## Included pages

- Overview dashboard
- Members directory
- Plans management
- Billing overview
- Reports dashboard
- Settings panel
